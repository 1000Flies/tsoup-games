# Prepared games for tsoup!

Pick a game. Download its package. Bring your own board.

These are prepared rules packages for **tsoup!**, the free Windows app for playing physical board games with AI opponents.

**New here? Download and install the app first:**
[Download tsoup! for Windows](https://github.com/1000Flies/tsoup/releases/tag/v0.8.0)

**Already have tsoup!? Get your game:**
[Download prepared games](https://github.com/1000Flies/tsoup-games/releases/tag/prepared-games-tsoup%21)

## How to use a package

1. On the prepared-games release page, open **Assets** and choose your game's **.tsoup** file. The **Source code** downloads are not game packages.
2. In tsoup!, go to **Library → Import package** and select the downloaded file.
3. Review the preview, choose **Import / update games**, and check the game's notes and included expansions before playing.

The app installer and game packages are separate downloads. You still need the physical board game. Ready rules can be reused for future matches; you do not prepare them again before every game.

If your game isn't here yet, prepare your own in tsoup! and share it with other players. The collection will grow over time. Testing varies by game; availability is not a promise that every situation has been tested.
